🔎 ค้นหาผู้บริจาค

ค้นด้วยเลขบัตร, Passport Number, ชื่อ, Donor ID หรือข้อมูลที่มี แล้วตรวจ Note / Defer / Sero-NAT ก่อนรับลงทะเบียน

📝 ลงทะเบียนผู้บริจาค

เลือก คนไทย หรือ ต่างชาติ/Passport → คนไทยใช้ Card Reader, Scanner หรือ “อ่านด้วยกล้อง” สำหรับบัตรประชาชน/ใบขับขี่/ภาพบัตรบนหน้าจอโทรศัพท์ → ระบบช่วยเติมข้อมูลจากบัตรและค่อยค้นประวัติหลังยืนยันตัวตน · ต่างชาติใช้ Scanner หรือ USB Camera อ่าน Passport/MRZ หรือกรอก Passport Number → ตรวจข้อมูล → บันทึก

📄 พิมพ์ใบสมัคร

เลือกวันที่ → ค้นผู้บริจาค → กดพิมพ์ใบสมัคร A4

📋 รายชื่อผู้บริจาคตามวันที่

ดูสถานะ เลขถุง รูปผู้บริจาค และแตะแถวเพื่อดูรายละเอียดทั้งหมด

🩺 คัดกรองผู้บริจาค

เลือกผู้บริจาค → ลง Weight / BP / Pulse / Temp / Hb → เลือกผ่านหรือไม่ผ่าน → กรอกข้อมูลถุงเฉพาะผู้ที่ผ่าน

🏷️ พิมพ์สติ๊กเกอร์

ใช้กับผู้บริจาคที่ผ่านและมีเลขถุง → ตรวจชื่อและเลขถุง → เลือกชุดสติ๊กเกอร์ → พิมพ์

📜 หนังสือรับรอง

เลือกผู้บริจาค → ตรวจข้อมูล → ออกเลขและพิมพ์หนังสือรับรอง

⚡ เตรียมออกหน่วย

อัปเดตฐานกลาง 4 Reports → ถ้ามีรายชื่อจากหน่วยให้นำเข้า “รายชื่อผู้บริจาคแจ้งล่วงหน้า” → ตั้งสถานที่/เลขถุง → วันจริงเลือกชื่อจากรายชื่อ → อ่านบัตร/สแกนหรือยืนยันเลขจริงก่อน → จึงค้น AI-LIS → ถ้าพบใช้ AI-LIS เป็นหลัก ถ้าไม่พบจึงใช้จำนวนครั้งที่หน่วยแจ้ง → ส่งออก LIS CSV

💳 Card Bridge

เปิด Start-CNMI-Card-Bridge.cmd ค้างไว้ → เสียบบัตรประชาชน → กด อ่านบัตรประชาชน ที่หน้าลงทะเบียน

🖨️ Scan Bridge

เปิด Start-CNMI-Scan-Bridge.cmd บนคอมที่ต่อ Scanner → ใช้สแกนบัตรประชาชน/ใบขับขี่ หรือ Passport → Passport จะอ่าน MRZ ด้านล่างเพื่อช่วยเติม Passport No. / ชื่อ / วันเกิด / เพศ / สัญชาติ
