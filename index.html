🔎 ค้นหาผู้บริจาค

ค้นด้วยเลขบัตร ชื่อ Donor ID หรือข้อมูลที่มี แล้วตรวจ Note / Defer / Sero-NAT ก่อนรับลงทะเบียน

📝 ลงทะเบียนผู้บริจาค

อ่านบัตรจากชิป หรือกดสแกนบัตร → ระบบอ่านเลข 13 หลักและค้นประวัติเดิม → ตรวจข้อมูล → ถ่ายรูปผู้บริจาคได้ถ้าต้องการ → บันทึก

📄 พิมพ์ใบสมัคร

เลือกวันที่ → ค้นผู้บริจาค → กดพิมพ์ใบสมัคร A4

📋 รายชื่อผู้บริจาคตามวันที่

ดูสถานะ เลขถุง รูปผู้บริจาค และแตะแถวเพื่อดูรายละเอียดทั้งหมด

🩺 คัดกรองผู้บริจาค

เลือกผู้บริจาค → ลง Weight / BP / Pulse / Temp / Hb → เลือกผ่านหรือไม่ผ่าน → กรอกข้อมูลถุงเฉพาะผู้ที่ผ่าน

🏷️ พิมพ์สติ๊กเกอร์

ใช้กับผู้บริจาคที่ผ่านและมีเลขถุง → ตรวจชื่อและเลขถุง → เลือกชุดสติ๊กเกอร์ → พิมพ์

📜 หนังสือรับรอง

เลือกผู้บริจาค → ตรวจข้อมูล → ออกเลขและพิมพ์หนังสือรับรอง

⚡ เตรียมออกหน่วย

อัปเดตฐานกลาง 4 Reports → ตั้งสถานที่ → ตั้งช่วงเลขถุง → ส่งออก LIS CSV → ถ้าเปลี่ยนคอม ให้ดาวน์โหลด “โปรแกรมสำหรับคอมเครื่องนี้” จากหน้าเตรียมออกหน่วย

💳 Card Bridge

เปิด Start-CNMI-Card-Bridge.cmd ค้างไว้ → เสียบบัตรประชาชน → กด อ่านบัตรประชาชน ที่หน้าลงทะเบียน

🖨️ Scan Bridge

เปิด Start-CNMI-Scan-Bridge.cmd บนคอมที่ต่อ Scanner → วางบัตรตรงไหนบนกระจก Flatbed ก็ได้ ขอให้ทั้งใบอยู่บนกระจก → กด สแกนบัตร/ใบขับขี่ → ระบบค้นหากรอบบัตร ครอป และ OCR อัตโนมัติ

☰ เมนูด้านซ้าย

เมนูจะเปิดค้างไว้ตามปกติ ถ้าต้องการพื้นที่หน้าจอเพิ่มให้กด ☰ เพื่อยุบ และกดซ้ำเพื่อขยาย

LIS Assistant: ทำทีละคนให้จบทั้งส่วนที่ 1 และส่วนที่ 2 ก่อนเปลี่ยนคน · ผ่านต้องยิง Barcode ถุงให้ตรง Expected Bag · ไม่ผ่าน Auto เฉพาะ 5 ค่า
